# 三类游戏声音合成数据

本批按 2024 年双耳声音定位与距离研究的**额外合成训练音频 20 小时**设置量级，并落实远距离占比较高、疏密分布不同的要求。每段为 6 秒、44.1 kHz、双声道 PCM16 WAV。完整统计及检查结果保存在数据目录中的 `summary.json`、`verification.json`。

**论文数据量核对**

| 论文 | 正文中使用的量级 | 本批的参考方式 |
| --- | --- | --- |
| [SELDnet，2019，III-A](https://arxiv.org/html/1807.00129v3) | ANSYN 每个交叉验证划分包含 240 段训练、60 段测试，每段 30 秒，即训练 2 小时、测试 0.5 小时；不同重叠级别分别构造 | 参考先划分源素材，再生成不同重叠的做法；不能把重复交叉验证折简单累加为独立原声 |
| [SELD-TCN，2020，III-A](https://arxiv.org/html/2003.01609v1) | 四个子数据集各 900 段 × 30 秒，即各 7.5 小时；60%/20%/20% 划分，分别为 4.5/1.5/1.5 小时 | 说明事件定位原型可从小时到几十小时的合成混合数据开始 |
| [声音检测、定位与距离估计，2024，III-A](https://arxiv.org/html/2403.11827v1) | 7 小时 22 分钟真实 STARSS23 录音，另合成 1,200 段 × 60 秒 = 20 小时，最多 3 个重叠声源；同时研究双耳版本 | 采用其 20 小时额外合成数据的训练时长；本批不包含论文的真实录音，也不复现其房间或类别 |

20 小时训练对应 12,000 段 × 6 秒。另加验证和测试各 1,500 段、各 2.5 小时，**总计 15,000 段、25 小时场景时间**。场景时长包含无目标声音的间隔，不等于 25 小时连续发声或独立原声。

**分布约定**

| 维度 | 设定 |
| --- | --- |
| 远近 | 每个划分内，按类别及密度分层分配：远约 65%、中约 25%、近约 10%；单位是声源轨迹，不是单发枪响数或总时长 |
| 密度 | 低 40%、中 35%、高 25% |
| 低密度 | 较长空白，偶发 1 路声音，部分为 2 路；脚步很短、枪声偶发、车船片段稀疏 |
| 中密度 | 以两类交替和间歇重叠为主，也包含三类及同类多方向组合 |
| 高密度 | 三路持续或频繁出现；多数是三种类别，也有同类两路加另一类，模拟多人声音重叠 |
| 方位 | 八方向，按各类别/远近/密度近似均衡，固定为该声源在本段中的来向 |
| 本批类别 | 脚步、车船、枪声；不含运输飞机正样本 |

低密度片段不强求每段、每一时刻都出现三种声音，否则无法产生早期场景较长的安静间隔。高密度提高事件频率和时间重叠，声源不会自动因为“密”就变近。

**音源与划分**

所有原声来自已核验的本机 PUBG 命名 SoundBank；重新只读提取，不下载音频。准备脚本找到 343 项候选，保留 330 个 PCM16/44.1 kHz 原声，排除 10 项 48 kHz 候选及 3 项完全重复 PCM。

- 脚步：82 个原声、6 个材质组；整种材质属于一个划分。
- 车船：25 个原声、24 个素材组；整组车型/声库属于一个划分，当前为怠速。
- 枪声：223 个原声、44 个枪械素材组；同一武器的变体属于同一划分。

先分组再安排声源、方向和距离；源 WAV/PCM 哈希、bank ID、media ID、PAK 位置随数据保存。小类别至少保留一个验证组和一个测试组，因此素材组数不一定精确等于 80%/10%/10%。原声数量及音色多样性不会因为生成 15,000 段就增加 15,000 倍。

四类模型接口保留运输飞机位置，但本批 `class_supervision_mask=[1,1,1,0]`，飞机相关损失必须屏蔽；不能将缺少飞机正例解释为每帧均已核验“没有飞机”。训练飞机类前另补独立数据。

**渲染与标注**

复用验收通过的 MIT KEMAR diffuse HRIR、八方向和近中远增益/低通。源参考增益先设置，再应用距离与 HRIR，最后按指定时间逐采样混合。双耳共用处理时基；每条轨迹有少量共同增益变化，脚步/枪声的时间和原声变体也会变化。

生成分两遍：第一遍扫描全批峰值，得到一个公共防削波增益；第二遍对所有划分使用这个相同增益保存 WAV。输出峰值上限 0.7，不逐片段或逐声道拉响，也不使用单独限幅器。该公共增益是生成参数，不是游戏音量标定。

每段的 `tracks/events` 保存类别、素材组、源文件 ID、方向、远近、起始采样点、增益及车辆裁剪位置。声源保持固定方向；车辆短片段的淡入淡出代表片段活动区间，并非物理行驶/转速仿真。枪声节奏为合成变化，不作为真实武器射速标注。原始 Near/Close 层也不被视为完全干声或零米参考。

每段另有 `.npz` 标签，按计划模型的 32 kHz、1024 点窗口、320 点步长对齐时间。6 秒对应 **597 帧**；音频保留 44.1 kHz，训练前双耳统一重采样到 32 kHz。

| 数组 | 形状/含义 |
| --- | --- |
| `activity` | 597×4×8；各类别与方向的活动标记 |
| `activity_loss_mask` | 同形状；飞机类及极弱、被掩蔽的正例可屏蔽监督 |
| `range_index` | 同形状；近/中/远为 0/1/2，无活动或同格距离冲突为 -1 |
| `range_loss_mask` | 同形状；仅活动、可观测且距离无冲突的格子为 1 |
| `active_track_count` | 同形状；记录落入格子的活动轨迹数量，不将其解释为人数 |
| `frame_right_edge_seconds` | 597；分析窗右端时间戳，从 0.032 秒开始，间隔 0.01 秒 |
| `class_supervision_mask` | 4；当前 `[1,1,1,0]` |

活动阈值来自各独立轨迹 32 ms 窗的能量：高于该轨迹最大窗能量的 -35 dB，并高于 -90 dBFS 绝对下限。用独立轨迹功率和估计干扰比，低于 -30 dB 的正例保留生成真值，但屏蔽对应损失，避免要求模型恢复几乎被完全盖住的声音。此阈值是工程近似，不能当成人耳可听性的实验结论。

同类同方向但不同远近的轨迹重叠时，该格距离设为 -1 并屏蔽距离损失。只训练有效距离格子，且同样应用活动/飞机屏蔽。不要把整个 6 秒都标成有枪声，也不要忽略原声尾部。

若训练辅助类别头，某类虽有生成正例但所有活动方向都被可观测性掩码屏蔽时，该帧该类的辅助损失也应屏蔽。试听索引取自验证集，供后续反馈和参数选择，测试集保留用于最终评估。

本批安静间隔主要是无目标声音的零值片段，尚不包含系统性的风雨、语音、爆炸等环境干扰库。可以用于本次三类合成训练；实战误报能力还需要背景负例和真实游戏片段验证。密度统计基于上述标签帧，不代表对人耳听感的标注。

- [可编辑配置](C:/Projects/PUBGAssistant-cpp/tools/audio/mix_dataset_v1.json)：数量、远近、密度、空间化参数。

在项目根目录，用安装了 NumPy 的 Python 3 运行；本机已使用随工作区提供的解释器，无需额外下载模型或声音。若修改配置或生成器，应给出新的输出目录，原目录的生成身份检查会阻止混用不同版本。

```powershell
python tools/audio/verify_mixed_dataset.py --dataset datasets/audio-synthetic-20260906-v1 --cache datasets/audio-synthetic-20260906-v1/render_cache_v1 --workers 4
```
