# 远处、曲线与自身声音：合成数据 v3

2026-09-06。生成器、逐帧标签和试听已实现；网络增加自身声音输出的设计，尚未训练。全量结果和程序校验见同目录的 `合成数据生成结果_v3.md`。

数据路径为 `C:/Projects/PUBGAssistant-cpp/datasets/audio-synthetic-20260906-v3/`，沿用此前核对论文后选定的量级：训练20小时、验证2.5小时、测试2.5小时，共3000段，每段30秒。旧v1、v2数据及其生成器保留。

## 远处声音与场景密度

外部声源的初始近/中/远配额改为10%/10%/80%。远处初始半径中心从105提高到168个合成单位，另有随机变化。脚步和车辆沿平滑曲线移动，因此初始远距离比例与实际发声帧的远距离比例不同；后者由完成后的标签统计。

低/中/高密度保持40%/35%/25%。低密度的活动时段短且空白多，高密度的持续活动和重叠更多。自身声音也按该场景密度安排，不会在全部前期场景中持续响起。

外部近处正例保留，不能把“距离很近”作为自身身份真值。当前外部代表“不是监听玩家自身”，包含其他玩家及其载具；不区分敌人、队友。

每次生成只使用一个公共主增益，不对某段音频或某个耳朵单独归一化。试听比较时应保持系统和播放器音量一致。距离为合成单位，不代表已校准的游戏米数。

## 自身身份及原声来源

| 类别 | 自身音频 | 位置及动作 |
|---|---|---|
| 脚步 | 同一地面的客户端原声变体，听者位置居中合成 | 相对位置固定；按动作速度连续累积步频，走、跑、冲刺及停步；左右仅为模拟交替标记 |
| 枪声 | 客户端 `Local` 枪声，保留原生双声道关系 | 相对位置固定，间歇开枪和连发 |
| 所乘车辆 | 客户端 `FPP` 启动/熄火；持续发动机沿用原生怠速变速与负载滤波近似 | 相对位置固定；另有行驶速度、转速、加减速及刹车控制轨迹 |

自身不是从音量或距离阈值推断出来的，recipe中明确记录 `source_role=self`。相对坐标和距离0表示绑定听者，不代表脚、枪口或发动机与耳朵的真实物理距离为0。自身方位不适用，不强行贴“前方”。自身脚步没有独立的原生FPP标签，当前原点声场属于近似；持续车内发动机也不等于还原游戏的REV模型。

自身脚步用于模拟原地踏步或听者相对固定的自身动作；当前没有另建玩家世界坐标运动并联动所有外部世界轨迹。模型不能仅凭这些合成例子被认定已适配真实游戏的自身声场。

自身轨迹每段最多一种主活动：脚步、枪声或所乘车辆，避免同时“步行又驾车”。各750段含对应自身声音，其中每类150段只有自身声音，600段混合外部声音；另有750段纯外部场景。后续可增加合理的边走边射击等联动动作。

同一枪型的Local与Remote、同一车辆的FPP与TPP保持同一家族划分；底层PCM去重后按家族隔离。只保留能支持外部原声的完整家族，避免某个枪型只在自身标签出现。脚步一条轨迹全程固定一种地面，绝不拿不同材质充当左右脚。

## 曲线与逐帧真值

外部轨迹先确定速度、展开的朝向角节点，再平滑插值并每10ms积分二维位置；方向由当前位置相对听者计算。停步、停车时位置连续且固定。声源沿轨迹使用连续的距离衰减、低通及双耳方向滤波，滤波历史跨节点保留。

WAV为44.1kHz双声道PCM16。标签对应网络32kHz前端的1024点窗口、320点步长、无末端补零：每30秒2997个分析帧，窗口右端时间为0.032、0.042……29.992秒。位置时刻为窗口中心减64/44100秒公共滤波延迟。自身渲染也补相同公共延迟。

每个声源在**每一帧**都有位置记录，包括当前没有发声的帧；活动标签单独表示是否发声。

| NPZ键 | 形状 | 含义 |
|---|---|---|
| `activity`、`activity_loss_mask` | T×4×8 | 外部类别×方向的活动及监督mask；自身不占方向格 |
| `range_index`、`range_loss_mask` | T×4×8 | 外部近中远0/1/2；无目标或冲突为-1并屏蔽损失 |
| `self_activity`、`self_activity_loss_mask` | T×3 | 自身脚步、所乘车辆、枪声独立活动及监督mask |
| `any_class_activity`、对应loss mask | T×4 | 外部和自身的类别并集，供辅助类别头使用 |
| `track_source_role` | K | 0外部，1自身 |
| `track_xy` | K×T×2 | 听者相对坐标，右为+x、前为+y；自身恒为0 |
| `track_distance_units` | K×T | 每帧连续距离；自身为相对位置0 |
| `track_azimuth_degrees` | K×T | 正前0°、右90°、后180°、左270°；自身0仅占位 |
| `track_direction_valid` | K×T | 外部1、自身0；使用角度前必须检查 |
| `track_sector_index`、`track_range_index` | K×T | 外部扇区0–7、距离档0–2；自身均为-1 |
| `track_activity` | K×T | 各源隔离渲染后的实际发声标签 |
| `track_speed` | K×T | 相对位置运动速度；自身为0 |
| `track_locomotion_speed` | K×T | 驱动脚步节奏或车辆转速的动作速度；自身可非0 |
| `track_gait_state`、`track_engine_state` | K×T | 步态、启停及车辆运行状态 |

T=2997，K是该场景声源数。方向真值对外部每帧完整，自身通过mask显式表示无方向。CSV导出自身角度为“不适用”，不把占位0显示成正前方。

活动阈值沿用每源峰值功率-35dB、绝对-90dBFS下限。外部可观测性计算包含自身干扰；被明显遮蔽的正例保留真值但屏蔽训练损失，不能当作可靠负例。距离冲突与飞机监督屏蔽规则保留。

## 训练接口调整

在现有192维因果TCN输出后增加 `Linear(192,3)` 和独立sigmoid，增加579个参数。总可训练参数1,243,855；解析估计每音频秒163,251,200 MAC，尚无实测速度。

初始损失为 `L_external + 0.2 L_range + 0.2 L_class_aux + 0.5 L_self`，每项应用对应mask并按有效元素数归一化。无有效元素时该项为0。每类正例权重只用训练集统计并暂时封顶20；自身损失权重需在验证集选择。

不得执行“近→自身→删除外部”的后处理。自身脚步和外部脚步可以同时为正；自身概率不能一票否决外部同类。除合成数据准确率外，后续要单独检查近处外部被误归自身、自己走动时远处声音漏检，以及真实游戏自身声音的误报/漏报。

飞机、真实背景及干扰素材仍未补齐，第四类监督mask仍为0。当前没有网络训练、ONNX或实时识别结果。原素材本身可能有截幅；公共增益保证本次混合没有新增输出削波，不能修复原录音失真。
